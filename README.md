# Gravit × AllUnity – Proof of Concept

**Epistemic Trust Layer for Agentic Payments (x402) and Multi-Currency Stablecoins**

This PoC demonstrates how Gravit verifies every AI‑agent transaction before settlement, providing cryptographic audit trails for BaFin/MiCAR compliance.

## Quick Start

```bash
git clone https://github.com/GravitOpenNetwork/gravit-allunity-poc.git
cd gravit-allunity-poc
make run
```

## Supported Assets

- CHFAU (Swiss franc, MiCAR-compliant)
- EURAU (Euro)
- SEKAU (Swedish krona)

## Key Features
- ✅ x402 Semantic Firewall
- ✅ Cross-currency bridge (CHF ↔ EUR ↔ SEK)
- ✅ BaFin-ready audit proofs
